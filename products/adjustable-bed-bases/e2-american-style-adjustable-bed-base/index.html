Product Features

Key Features

Features shown below reflect the current model configuration. Final control, electrical and project-specific options are confirmed for each order or project.

Full-frame structure

Uses a full-frame structure. Final packaging and handling requirements are confirmed according to the selected configuration.

01

Head and foot lift

The head and foot sections can be adjusted for different reclining and resting positions. The positioning function is integrated into the model’s full-frame structure.

02

Zero gravity

Activates the model’s zero-gravity preset position through the control system. It provides direct access to a consistent preset position when selected.

03

One-touch flat

Returns the adjustable sections to a flat platform using a single control command. This makes it easier to reset the base after position changes.

04

Child lock

Includes a child-lock function as part of the model’s control features. Final operating details are confirmed according to the selected control configuration.

05

Mobile App control

Supports control of the adjustable functions through a compatible mobile application. The application serves as an additional operating interface alongside the available controller.

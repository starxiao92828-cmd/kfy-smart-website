Key Features

Features shown below reflect the current model configuration. Final control, electrical and project-specific options are confirmed for each order or project.

Independent head and foot lift

The head and foot sections can be controlled separately to create different reclining positions. Each section can be adjusted according to the required bed configuration.

Synchronized lift

Provides coordinated adjustment through a synchronized control function. It offers a combined movement option within the model’s available positioning controls.

One-touch flat

Returns the adjustable sections to a flat position with one control command. This provides a simple reset after using an adjusted position.

Sliding mode

Includes a sliding function as part of the model’s adjustable structure. The exact movement configuration is confirmed for each order or project.

Zero gravity

Activates the model’s zero-gravity preset position from the control system. The function provides direct access to a repeatable preset position.

Underbed light

Provides low-level illumination beneath the bed base to improve visibility in dark rooms. It helps users see the floor area around the bed without requiring additional room lighting.

# KFY SMART V2 Clean Website

Static HTML/CSS/JS website package for KFY SMART.

## Deployment
Upload all files in this folder to the existing GitHub repository `starxiao92828-cmd/kfy-smart-website`. If the existing Vercel project is connected to GitHub, Vercel will deploy automatically after pushing to the production branch.

## Pages
- `index.html`
- `products.html`
- `news.html`
- `about.html`
- `contact.html`
- `404.html`

Old pages are kept as simple transition pages to avoid 404s.
